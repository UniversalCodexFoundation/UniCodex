## 发现的问题

### BUG-001: `ucx version chapter` 可能导致版本降级

- **严重程度**：中
- **现象**：版本从 2.3.0 降级为 2.1.0
- **原因**：`bump_chapter` 从 struct.json 读取当前章节数（1），直接设为 Y，未与当前版本的 Y 值比较
- **根因位置**：`unicodex-core/src/main.rs` 第 863-871 行
- **建议修复**：`bump_chapter` 应取 `max(current.chapter + 1, struct_chapter_count)` 作为新 Y 值

### UX-001: `--path` 参数不适用于 version 子命令

- **严重程度**：低（设计问题）
- **现象**：`ucx version set 1.0.0 --path <dir>` 报 `unexpected argument '--path' found`
- **原因**：CLI 定义中 `--path` 仅在 `version` 父命令上定义，子命令未继承
- **变通方法**：将 `--path` 放在子命令之前：`ucx version --path <dir> set 1.0.0`
- **建议改进**：在子命令中也接受 `--path`，或在 help 中明确说明参数位置

### UX-002: `ucx info` 不显示 file_version 信息

- **严重程度**：低（功能缺失）
- **现象**：人类可读输出中不显示 file_version，仅 `--json` 和解压 codex.json 能看到
- **建议**：有 file_version 时增加一行 `File Version: X.Y.Z (revision N)` 显示

### NOTE-001: `version auto` 在 Y=0 时的校正行为

- **现象**：tag `ucx-v1.0.0` 后修改内容，auto 结果为 1.1.1 而非 1.0.1
- **原因**：当 current.chapter == 0 时，代码从 struct.json 校正 Y 值
- **评估**：这是有意设计，确保版本号反映实际结构状态，非 bug
