## 三、正向确认

**加密 (R2)**：
- KDF 篡改不再 panic，全部返回 "decryption failed"
- Chunked nonce 拼接式生效，同密钥同明文密文不同
- AES-GCM / ChaCha20 AAD 对头部保护有效
- KDF 参数上下限校验到位
- NFC 归一化生效，跨平台密码互通
- 空文件 / 全零密钥 / 65MiB chunked 均 roundtrip 正常

**鲁棒性 (R3)**：
- ZIP 签名校验、UCX-Version MAJOR 限制、路径约束、保留名拒绝全部生效
- 版本字符串 6 种畸形写法全部被拒
- 反斜杠路径明确报错 "use forward slashes"
- 空目录、TOML 语法错、unpack 路径穿越防御保持

**签名 (R4)**：
- 过期/未生效证书 → INVALID（含 notBefore/notAfter 详情）
- cert.pem 与 EC 内嵌 cert 不一致 → INVALID（双指纹对比）
- hash mismatch → INVALID（非 PARTIAL）
- 私钥文件 ACL 仅当前用户
- UCXE magic 检测友好提示
- 完整链路 encrypt→build→sign→verify→decrypt 端到端通过

---

## 四、结论

v0.4.0-alpha.2 对 v0.4.0-alpha.1 的 **28 项回归验证中 26 项 FIXED（92.9%）**，1 项 NOT-FIXED（`--force` 分支 bug），1 项 PARTIAL（AAD reserved bits）。

新发现 11 项均为 Medium 及以下，**无 Critical / High / Blocker**。签名子系统 5/5 全通过，加密子系统核心安全漏洞全部修复。

**建议**：v0.4.0-alpha.2 可进入 beta 阶段。NEW-R1-01（--force bug）和 NEW-R2-01（AAD reserved bits）建议作为 v0.4.0-beta.1 的必修项。
